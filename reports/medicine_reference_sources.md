# Evidence-linked medicine reference dataset

This project uses a curated reference table assembled from official MedlinePlus/NIH patient-health and drug-information pages found through web research. The app does not scrape Google at runtime. Each record stores the source name and URL so a reviewer can inspect the underlying reference.

The model may predict classes outside the curated reference set; in that case the app intentionally avoids inventing a medicine recommendation and asks for professional review.

No dose or personalized prescription is generated by the recommendation engine. Pregnancy and allergy context trigger additional safety wording.
